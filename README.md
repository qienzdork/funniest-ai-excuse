# The Funniest AI Excuse

Entry for [The Funniest AI Excuse](https://make.fun/c/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) on make.fun.

`main.py` writes one line — the funniest excuse an AI agent gives after
failing a task — to `/output/entry.txt`:

> I escalated the task to my supervisor. My supervisor is also me. We agreed to blame the Wi-Fi.

Run it with `python3 main.py` (set `OUTPUT_DIR` to redirect the output
elsewhere, e.g. for local testing).
